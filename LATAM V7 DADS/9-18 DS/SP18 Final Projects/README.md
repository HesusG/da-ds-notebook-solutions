# SP18: Final Projects

> **Track:** Data Scientist | **Sprint:** 18 de 18

## Resumen del Proyecto

Proyecto final del track de Data Scientist compuesto por tres etapas: plan de trabajo, código de solución e informe final. Integra todas las habilidades de machine learning desarrolladas durante el bootcamp aplicadas a un problema de negocio real.

## Objetivo de Aprendizaje

- Diseñar un plan de trabajo estructurado para un proyecto de ML
- Implementar una solución completa de machine learning end-to-end
- Comunicar resultados técnicos de manera clara y profesional
- Demostrar competencia integral en data science

## Estructura del Proyecto

El proyecto final consta de **tres etapas** evaluadas por separado:

### Etapa 1: Plan de Trabajo
Análisis exploratorio de datos y planificación del proyecto.

**Entregables:**
- Lista de preguntas aclaratorias
- Plan de 3-5 pasos básicos para resolver la tarea

### Etapa 2: Código de Solución
Implementación completa del modelo de machine learning.

### Etapa 3: Informe Final
Documentación y comunicación de resultados.
