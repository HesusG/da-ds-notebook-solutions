# SP14: Final Projects

> **Track:** Data Analyst | **Sprint:** 14 de 14

## Resumen del Proyecto

Proyecto final del track de Data Analyst compuesto por múltiples componentes: prueba A/B, consultas SQL, y un caso principal de análisis. Integra todas las habilidades desarrolladas durante el bootcamp.

## Objetivo de Aprendizaje

- Integrar habilidades de análisis de datos completas
- Diseñar y ejecutar análisis end-to-end
- Comunicar resultados efectivamente (presentación)
- Demostrar competencia en SQL y Python

## Estructura del Proyecto

El proyecto final consta de **tres etapas** evaluadas por separado:

### Etapa 1: Prueba A/B
Análisis de resultados de test A/B para tienda online.

### Etapa 2: Manejo de SQL
Consultas SQL para análisis de datos de una aplicación.

### Etapa 3: Caso Principal
Proyecto de análisis completo con descomposición e implementación.
