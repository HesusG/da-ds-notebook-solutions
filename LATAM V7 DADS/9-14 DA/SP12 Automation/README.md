# SP12: Automation

> **Track:** Data Analyst | **Sprint:** 12 de 14

## Resumen del Proyecto

Creación de un dashboard interactivo en Tableau Public para automatizar el análisis de tendencias de videos en YouTube. El dashboard permite filtrar por fecha y país para obtener insights sobre categorías populares y distribución geográfica.

## Objetivo de Aprendizaje

- Diseñar dashboards interactivos con filtros globales
- Crear visualizaciones efectivas (áreas apiladas, heatmaps, pie charts)
- Publicar y compartir reportes en Tableau Public
- Automatizar procesos de reporting

## Dataset

| Archivo | Descripción |
|---------|-------------|
| `trending_by_time.csv` | Datos de videos en tendencia por categoría, país y tiempo |
