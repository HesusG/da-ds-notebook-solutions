# Projects Solutions

This repo contains the solutions for every project and should be the most updated version there is. Every project should be committed as a script (.py if it is a Python script), not as Interactive PYthon NoteBooks (.ipynb) since they are not suitable for version control.

You can easily transform a .py into a .ipynb file and vice versa if you so want it. You can also convert it into a .qmd file, which is much better IMO (Rodo). But let's start with .py files.

The datasets should be placed in a directory called `datasets/*`. Do not use `/datasets/*`, since that is an absolute path, hence, it is not replicable. The `datasets` directory is part of the repo, but it is empty. That is fine. We should commit datasets.

You can download all of the datasets from this link (datasets were downloaded more than a year ago, we need to update that eventually).

When you want to run a project, always work with this repo's folder. Open this folder and start executing your code. This will improve the reproducibility and reduce the possibility of finding or introducing bugs.
