### Descripción del proyecto
---
**El Desafío: datos de VentaExpress**

Has recibido un archivo de datos de ventas que contiene información valiosa, pero que presenta varios problemas típicos que encontrarás en el mundo real:

- Datos con formato inconsistente.
- Valores duplicados y ausentes.
- Columnas desorganizadas.
- Información que necesita ser dividida o combinada.
- Falta de una documentación clara.

Tu misión es transformar estos datos caóticos en un informe profesional y comprensible que responda a las preguntas clave del negocio.
