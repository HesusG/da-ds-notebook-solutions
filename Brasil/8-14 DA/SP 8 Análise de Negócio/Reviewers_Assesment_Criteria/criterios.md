## Technical Glossary

| Term | Definition |
|------|------------|
| **DAU** | Daily Active Users - unique visitors per day |
| **WAU** | Weekly Active Users - unique visitors per week |
| **MAU** | Monthly Active Users - unique visitors per month |
| **Retention Rate** | Percentage of users who return after their first visit |
| **Conversion** | Percentage of visitors who make a purchase |
| **LTV (Lifetime Value)** | Total revenue generated by a customer over their lifetime |
| **CAC (Customer Acquisition Cost)** | Cost to acquire one paying customer |
| **ROMI (Return on Marketing Investment)** | LTV / CAC - profitability of marketing spend |
| **Cohort** | Group of users who started using the product in the same time period |
| **Cohort Analysis** | Tracking behavior of user groups over time |

## Compliance Examples

### Correct DAU/WAU/MAU Calculation
```python
# Extract date features
visits['session_date'] = visits['session_start_ts'].dt.date
visits['session_week'] = visits['session_start_ts'].dt.isocalendar().week
visits['session_month'] = visits['session_start_ts'].dt.month

# Calculate metrics
dau = visits.groupby('session_date').agg({'uid': 'nunique'})
wau = visits.groupby('session_week').agg({'uid': 'nunique'})
mau = visits.groupby('session_month').agg({'uid': 'nunique'})

print('DAU:', int(dau.mean().iloc[0]), 'visitors')  # ~907
print('WAU:', int(wau.mean().iloc[0]), 'visitors')  # ~5825
print('MAU:', int(mau.mean().iloc[0]), 'visitors')  # ~23228
```

### Correct Retention Rate Calculation
```python
# Find first session per user
first_visits = visits.groupby('uid').agg({'session_start_ts': 'min'}).reset_index()
first_visits.columns = ['uid', 'first_session_ts']
first_visits['first_session_month'] = first_visits['first_session_ts'].dt.month

# Merge with all visits
visits_full = pd.merge(first_visits, visits, on='uid')
visits_full['age_months'] = visits_full['session_month'] - visits_full['first_session_month']

# Create cohort pivot table
cohorts = visits_full.pivot_table(
    index='first_session_month',
    columns='age_months',
    values='uid',
    aggfunc='nunique'
)

# Calculate retention rate
retention = cohorts.divide(cohorts[0], axis=0)
```

### Correct LTV Calculation
```python
# Group buyers by first order month
cohort_sizes = buyers.groupby('first_order_month').agg({'uid': 'nunique'}).reset_index()
cohort_sizes.columns = ['first_order_month', 'n_buyers']

# Sum revenue per cohort per order month
cohorts_revenue = orders.merge(buyers[['uid', 'first_order_month']], on='uid')
cohorts_revenue = cohorts_revenue.groupby(['first_order_month', 'order_month']).agg({'revenue': 'sum'}).reset_index()

# Calculate age and merge
cohorts_revenue['age_month'] = (cohorts_revenue['order_month'] - cohorts_revenue['first_order_month']).apply(lambda x: x.n)
report = pd.merge(cohort_sizes, cohorts_revenue, on='first_order_month')
report['ltv'] = report['revenue'] / report['n_buyers']

# Create cumulative LTV pivot
ltv_pivot = report.pivot_table(index='first_order_month', columns='age_month', values='ltv').cumsum(axis=1)
```

### Correct CAC Calculation
```python
# Total CAC
total_cac = costs['costs'].sum() / orders['uid'].nunique()
print(f"Mean CAC: ${total_cac:.2f}")  # ~$9.01

# CAC by source (requires first-touch attribution)
users = visits.sort_values('session_start_ts').groupby('uid').first()[['source_id']]
buyers_with_source = buyers.merge(users, left_on='uid', right_index=True)

# Calculate CAC per source
cac_by_source = costs.groupby('source_id').agg({'costs': 'sum'})
buyers_by_source = buyers_with_source.groupby('source_id').agg({'uid': 'nunique'})
cac_by_source['cac'] = cac_by_source['costs'] / buyers_by_source['uid']
```

## Disqualification Criteria

The following errors result in automatic failure:

1. **Wrong aggregation level** - Counting total visits instead of unique users for DAU/WAU/MAU
2. **Missing cohort analysis** - No retention or LTV analysis by cohort
3. **Wrong ROMI formula** - Using revenue/cost instead of LTV/CAC
4. **No source attribution** - Calculating CAC without linking users to their acquisition source
5. **Cumulative calculation error** - Not using `.cumsum()` for LTV and ROMI over time

## Common Errors

### Error 1: Counting Sessions Instead of Users
| Aspect | Description |
|--------|-------------|
| **Incorrect** | `dau = visits.groupby('session_date')['uid'].count()` |
| **Correct** | `dau = visits.groupby('session_date')['uid'].nunique()` |
| **Consequence** | Inflates DAU by counting repeat visits from same user |

### Error 2: Wrong Retention Calculation
| Aspect | Description |
|--------|-------------|
| **Incorrect** | Using all users instead of cohort-specific first-month users as denominator |
| **Correct** | Divide each cohort row by its own age=0 value: `cohorts.divide(cohorts[0], axis=0)` |
| **Consequence** | Retention rates will be incorrect and not comparable across cohorts |

### Error 3: Non-Cumulative LTV
| Aspect | Description |
|--------|-------------|
| **Incorrect** | Showing revenue per month without accumulation |
| **Correct** | Using `.cumsum(axis=1)` to show cumulative LTV over customer lifetime |
| **Consequence** | Cannot assess total customer value over time |

### Error 4: Last-Touch Attribution for CAC
| Aspect | Description |
|--------|-------------|
| **Incorrect** | Attributing purchase to last source before conversion |
| **Correct** | First-touch attribution: `visits.sort_values('session_start_ts').groupby('uid').first()` |
| **Consequence** | Misattributes acquisition cost to wrong sources |

### Error 5: Dividing by Total Users Instead of Buyers
| Aspect | Description |
|--------|-------------|
| **Incorrect** | `CAC = total_costs / total_visitors` |
| **Correct** | `CAC = total_costs / total_buyers (unique purchasing users)` |
| **Consequence** | Underestimates true customer acquisition cost |

### Error 6: Not Handling Period Arithmetic Correctly
| Aspect | Description |
|--------|-------------|
| **Incorrect** | `(order_month - first_order_month) / np.timedelta64(1,'M')` (deprecated) |
| **Correct** | `(order_month - first_order_month).apply(lambda x: x.n)` for Period objects |
| **Consequence** | Age calculation fails or produces wrong values with newer pandas versions |
