Sprint 4: Data Wrangling
===============================

Project Description
-------------------
This project involves working with a modified dataset from Instacart, a grocery delivery platform similar to Uber Eats or DoorDash. The dataset is based on one released in 2017 for a Kaggle competition and has been adjusted to include missing and duplicate values while preserving the original data distributions.

The main objective is to clean the data and create a report that provides insights into the shopping habits of Instacart customers. The tasks include:

1. Answering specific questions through data analysis.
2. Documenting findings in markdown cells within a Jupyter Notebook.
3. Creating clear and effective visualizations with titles, labeled axes, and legends when necessary, ensuring to display the plots using plt.show().
4. The project emphasizes presenting findings through informative graphs and clear reporting.




Data Dictionary
---------------
The dataset consists of five tables, each containing information necessary for data preprocessing and exploratory data analysis (EDA):

1. instacart_orders.csv: Contains information about customer orders.

a) 'order_id': Unique order identifier.
b) 'user_id': Unique customer identifier.
c) 'order_number': Number of orders placed by the customer.
d) 'order_dow': Day of the week the order was placed (0 = Sunday).
e) 'order_hour_of_day': Hour of the day the order was placed.
f) 'days_since_prior_order': Days since the customer’s last order.

2. products.csv: Lists details about products available for purchase.

a) 'product_id': Unique product identifier.
b) 'product_name': Name of the product.
c) 'aisle_id': Unique identifier for the grocery aisle category.
d) 'department_id': Unique identifier for the grocery department category.

3. order_products.csv: Details the items within each order.

a) 'order_id': Unique order identifier.
b) 'product_id': Unique product identifier.
c) 'add_to_cart_order': Order in which items were added to the cart.
d) 'reordered': 0 if the product is new for the customer, 1 if reordered.

4. aisles.csv: Describes grocery aisle categories.

a)'aisle_id': Unique identifier for the aisle.
B) 'aisle': Name of the aisle.

5. departments.csv: Details grocery department categories.

a) 'department_id': Unique identifier for the department.
b) 'department': Name of the department.
