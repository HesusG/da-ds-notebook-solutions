# Sprint 7: Software Development Tools
## EN: Software Development Tools
📅 English version last update: unknown (before 2025)

⛔ This project does not start with a template for the student.

**Objective**
---------
This sprint focuses on software engineering practices that complement data analysis skills, making you a more versatile and employable professional. The project will introduce essential tools used in software development, including Python virtual environments, web application development, and cloud deployment.

Unlike previous sprints that emphasized data analysis, this project shifts its focus to software engineering fundamentals. You will work with a dataset (provided or self-chosen) but the primary goal is developing and deploying a functional web application, rather than analyzing the data itself.

Additionally, the project submission format will be different from previous sprints. Instead of working within a Jupyter Notebook, students will submit their work through a repository link (e.g., GitHub or GitLab), where they will upload all project files, including code, configurations, and deployment instructions.

## ESP: Herramientas de desarrollo de software
📅 Fecha de actualización versión en español: 16 Julio 2025

⛔ El proyecto no tiene plantilla o precodigo para el estudiante.

### Descripción del proyecto
El objetivo de este proyecto es proporcionarte más posibilidades de practicar las tareas habituales de la ingeniería de software. Gracias a estas tareas, podrás aumentar y complementar tus habilidades en el campo de los datos y te convertirás en un candidato más atractivo para posibles empleadores.

Las tareas incluyen la creación y gestión de entornos virtuales de Python y el desarrollo de una aplicación web.

En este proyecto, te proporcionamos un conjunto de datos de anuncios de venta de coches. Sin embargo, en este proyecto, el enfoque no se centrará en el conjunto de datos ni en el análisis, por lo que eres **libre de elegir cualquier dataset que desees**.

### Entregables
Enlace al repositorio de Github con:
- Archivo `README.md` con:
  - link a la página desplegada con Render
- Archivo `requirements.txt` con las librerias necesarias.
- Archivo `EDA.ipynb` con el análisis exploratorio de datos.
- Archivo `app.py` con el código de la página web.

## PT: S5 Ferramentas de Desenvolvimento de Software
📅 Data de atualização da versão em português: 17 de julho de 2025

⛔ O projeto não tem template ou código inicial para o estudante.

### Descrição do projeto
O foco desse projeto é que você tenha mais prática com tarefas comuns de engenharia de software. Isso vai aprimorar e complementar suas habilidades de dados e vai fazer com que você seja uma opção mais atrativa para possíveis empregadores.

As tarefas são: criar e gerenciar ambientes virtuais de Python, desenvolver um aplicativo web e implantá-lo em um serviço de nuvem que o tornará acessível ao público.

Neste projeto, vamos fornecer um conjunto de dados de anúncios de vendas de carros. No entanto, neste projeto, o foco não será no conjunto de dados nem na análise, então você está **livre para escolher o conjunto de dados que desejar**.

Link para o repositório do Github com:
- Arquivo `README.md` contendo:
  -link para a página publicada no Render
